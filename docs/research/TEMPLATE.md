# Research Report Template

复制本模板到 `docs/research/R-<nnnn>-<slug>.md` 使用（协议 §6）。Researcher 默认 L0 权限：只读 repo/internet，可跑实验，只写 docs/research/。

```markdown
# Question

需要回答什么？

# Context

为什么需要研究？（关联 plan/ADR）

# Candidates

可能方案有哪些？

# Evidence

论文 / 文档 / 源码 / benchmark / 实验结果（附可复现命令与原始数据位置）

# Findings

发现了什么？

# Recommendation

推荐方案。

# Confidence

0.0 - 1.0

# Unknowns

仍然不知道什么？
```

规则：能实验的问题优先实验（协议 §1.3）；结论将进入 ADR 的 Evidence 栏。

# ADR-0001: 采用《AI 自治研发协议 v0.1》作为项目治理协议

- 状态：Accepted
- 日期：2026-08-22

## Context

人类明确指示：本项目今后全部由 AI 进行研发。需要一个覆盖研究、设计、实现、测试、评审、维护全流程的治理框架，使任意新会话的 Agent 能在无聊天上下文的情况下接续工作。

## Decision

采纳《Autonomous Development Protocol / AI 自治研发协议 v0.1》，逐字保存于 `docs/protocol/autonomous-development-protocol.md`，作为本仓库最高治理文件。项目本地化配置（升级阈值数字、渠道、超时策略）见 `docs/quality/escalation-policy.md`。

## Alternatives

- 无正式协议、依赖会话记忆推进：违反"Repository is memory"，不可审计，否决；
- 更重的多角色公司式框架（CEO/CTO Agent 等）：协议 §36 明确列为 anti-pattern，否决。

## Evidence

人类直接指令（2026-08-22 会话）。协议本身由人类撰写并要求保存。

## Consequences

- 默认自治执行；仅 E1–E7 条件可打扰人类；
- 一切跨 Agent 交流通过 artifact（research/ADR/plan/task packet/commit/review）；
- `make check` 为宣告完成前的强制机械门；
- 正常运行时保持静默，仅里程碑/异常/每日简报上报。

## Risks

过度自治导致方向漂移 → 由协议 §19 升级条件与 escalation-policy 的数字约束兜底。

## Rollback

以新 ADR 取代本决策；协议文本本身不修改（修订须人类发起）。

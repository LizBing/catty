# briefs/ — 项目简报

每日最多一份（协议 §21 Silence Principle、§22 Daily Project Brief），命名 `YYYY-MM-DD.md`。人类可以完全不回复。

```markdown
# PROJECT BRIEF YYYY-MM-DD

Completed: N
In progress: N
Blocked: N

Merged:
- (PR / commit 列表)

Performance:
- (关键指标变化，附证据链接)

New risks:
- (无则写 none)

Human decisions required:
- (无则写 none —— 有则必须用协议 §20 的 DECISION REQUIRED 格式)
```

升级类消息不走 brief，直接通过升级渠道发送（见 docs/quality/escalation-policy.md）。
